## 📋 Daftar Tools yang Telah Dibuat

### 1. 🚀 File & Image Optimizer Pro (`file-optimizer`)
- **Lokasi Folder**: [`/home/Gilang/tools/file-optimizer`](file:///home/Gilang/tools/file-optimizer)
- **Fungsi Utama**: Tool & SDK untuk mengecilkan ukuran file gambar berukuran besar (seperti gambar 16 MB menjadi **< 2 MB**) tanpa menurunkan resolusi (*width × height*) dan tetap mempertahankan kualitas visual yang tajam.
- **Fitur Unggulan**:
  - **100% Retensi Resolusi Asli**: Dimensi piksel gambar asli dipertahankan 100%.
  - **Client-Side Processing**: Berjalan sepenuhnya di dalam browser (aman, cepat, dan privasi terjaga).
  - **Visual Split-Screen Comparison**: Perbandingan visual interaktif *Before vs After*.
  - **Website Integration SDK (`FileOptimizerSDK`)**: Dapat dipasang di website eksternal mana pun untuk mengompresi file yang diunggah pengguna secara otomatis sebelum disimpan ke database/server.
  - **Batch Compression**: Mengolah banyak file sekaligus dan ekspor hasil ke format ZIP.
- **Tautan Cepat**:
  - 📄 [README File Optimizer](file:///home/Gilang/tools/file-optimizer/README.md)
  - 📖 [Dokumentasi Integrasi Website](file:///home/Gilang/tools/file-optimizer/dokumentasi.html)
  - 🧪 [Demo Live Integrasi SDK](file:///home/Gilang/tools/file-optimizer/integration-demo.html)

## 🛠️ Panduan Menambah Tool Baru di Masa Depan

1. Buat folder baru di dalam direktori `tools/` dengan nama yang jelas dan profesional (menggunakan format *kebab-case*), contoh:
   - `pdf-compressor/`
   - `media-converter/`
   - `code-formatter/`
2. Sertakan file `README.md` di dalam folder tool baru tersebut untuk menjelaskan fungsi dan cara menjalankannya.
3. Daftarkan tool baru tersebut pada tabel / daftar di file `README.md` utama ini.

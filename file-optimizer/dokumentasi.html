Panduan Pengembang Website

Dokumentasi Integrasi FileOptimizer SDK

Panduan lengkap mengintegrasikan modul kompresi otomatis ke dalam website Anda. Setiap pengguna mengunggah foto/gambar (misal 16 MB), ukurannya secara otomatis dikompresi menjadi kurang dari 2 MB (< 2 MB) di browser sebelum di-submit ke database/server.

1. Keuntungan & Cara Kerja Integrasi

FileOptimizerSDK bekerja di sisi klien (*Client-Side Browser*). Pengguna memilih gambar berukuran besar seperti biasa. SDK akan secara transparan mengompresi file tersebut tanpa mengubah piksel resolusi asli gambar.

  • Bebas Bebas Ukuran Upload: Pengguna tidak perlu mengecilkan foto secara manual.
  • Hemat Storage Database: Server hanya menyimpan file terkompresi hemat memori (< 2 MB).
  • Resolusi 100% Utuh: Dimensi lebar × tinggi gambar tetap sama persis seperti gambar asli.
  • Server Bebas Beban: Kompresi terjadi di browser pengguna, sehingga server tidak akan lemot/lag.

2. Metode A: Auto-Attach ke Input File (Paling Ringkas)

Metode ini secara otomatis meng-intercept elemen <input type="file"> di website Anda. Saat pengguna memilih file gambar besar, file pada input tersebut langsung diganti dengan versi terkompresi < 2 MB secara otomatis.

// 1. Import SDK pada file JavaScript website Anda import { FileOptimizerSDK } from './src/sdk/FileOptimizerSDK.js'; // 2. Hubungkan ke elemen input upload di website Anda FileOptimizerSDK.attachToInput('#myFileInput', { maxSizeBytes: 2 * 1024 * 1024, // Garansi ukuran file < 2 MB onStart: (files) => { console.log('Proses kompresi dimulai...'); }, onSuccess: (compressedFiles) => { console.log('File berhasil dikompresi < 2MB:', compressedFiles[0]); // File pada input otomatis diganti dan siap di-submit form } });

3. Metode B: Kompresi Manual via API Function (Untuk AJAX / Fetch Upload)

Gunakan fungsi FileOptimizerSDK.compress(file) jika Anda mengelola proses upload secara manual (misalnya dengan Fetch API, Axios, atau React/Vue state).

import { FileOptimizerSDK } from './src/sdk/FileOptimizerSDK.js'; async function handleUpload(event) { const fileAsli = event.target.files[0]; // Kompresi file 16MB menjadi < 2MB dengan resolusi 100% utuh const fileTerkompresi = await FileOptimizerSDK.compress(fileAsli, { maxSizeBytes: 2 * 1024 * 1024 // Target limit 2 MB }); console.log('Ukuran Asli:', fileAsli.size); // Contoh: 16,400,000 bytes console.log('Ukuran Baru:', fileTerkompresi.size); // Contoh: 1,200,000 bytes (< 2 MB) // Kirim file terkompresi ke backend/database const formData = new FormData(); formData.append('image', fileTerkompresi); await fetch('/api/upload', { method: 'POST', body: formData }); }

4. Opsi Konfigurasi (SDK Options)

Berikut adalah parameter opsional yang dapat Anda atur sesuai kebutuhan website:

Parameter Tipe Data Default Value Keterangan
maxSizeBytes Number 2097152 (2 MB) Batas maksimal ukuran file target dalam bytes.
format String 'image/webp' Format output hasil kompresi ('image/webp', 'image/jpeg', 'image/png').
quality Number 0.82 Faktor kualitas awal (range 0.1 hingga 1.0).
onStart Function null Callback yang dipanggil saat kompresi dimulai.
onSuccess Function null Callback saat file berhasil dikompresi < 2 MB.
onError Function null Callback jika terjadi kesalahan saat proses membaca file.

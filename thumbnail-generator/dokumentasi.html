Dokumentasi Integrasi ThumbnailSDK

Otomatiskan pembuatan foto sampul mini WebP (< 15 KB) untuk daftar file di Unara Storage atau website Anda.

1. Otomatiskan Pembuatan Thumbnail dari Input File

import { ThumbnailSDK } from './src/sdk/ThumbnailSDK.js';

ThumbnailSDK.attachToInput('#fileUpload', {
  size: 150, // 150x150 px
  onSuccess: (thumbnails) => {
    console.log('Thumbnail WebP mini siap diunggah:', thumbnails[0]);
  }
});

2. Panggilan Fungsi Manual (Foto, Video, PDF)

import { ThumbnailSDK } from './src/sdk/ThumbnailSDK.js';

const originalFile = event.target.files[0];
const thumbnailFile = await ThumbnailSDK.generate(originalFile, { size: 150 });

// thumbnailFile adalah objek File berformat WebP (< 15 KB)

Dokumentasi Master GilangStorageSDK

Satu-satunya SDK master yang Anda butuhkan untuk menghubungkan website klien mana pun ke server penyimpanan Gilang Storage.

1. Instalasi Resmi via NPM

npm install gilang-storage-sdk

2. Integrasi 1 Baris Kode Input Interceptor

import { GilangStorageSDK } from 'gilang-storage-sdk';

GilangStorageSDK.attachToInput('#fileUpload', {
  apiEndpoint: 'https://storage-api.com/api/upload',
  onSuccess: (results) => {
    console.log('File ter-sanitasi, terkompresi & ter-upload:', results[0]);
  }
});

3. Panggilan Programatis Manual

import { GilangStorageSDK } from 'gilang-storage-sdk';

const userFile = event.target.files[0];

// Otomatis: Security Check ➔ Smart Compress (< 2 MB) ➔ WebP Thumbnail (< 15 KB)
const result = await GilangStorageSDK.process(userFile);

console.log('File Siap Upload:', result.processedFile);
console.log('Thumbnail Mini:', result.thumbnailFile);

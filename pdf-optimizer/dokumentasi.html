Dokumentasi Integrasi PdfOptimizer SDK

Panduan integrasi modul kompresi PDF otomatis ke website Anda. Setiap kali pengguna mengunggah file PDF besar (misal 10 MB - 50 MB), SDK akan mengompresinya secara otomatis menjadi kurang dari 2 MB (< 2 MB) tanpa mengirim file ke server eksternal.

1. Keuntungan Integrasi Client-Side

  • Privasi Mutlak: Dokumen PDF rahasia (KTP, Slip Gaji, Ijazah) tidak pernah dikirim ke server luar.
  • Teks & Vektor Presisi: Teks dokumen tetap 100% tajam dan tetap dapat di-copy.
  • Hemat Storage Database: Server hanya menyimpan file PDF yang sudah terkompresi < 2 MB.

2. Metode A: Auto-Attach pada Input File PDF

import { PdfOptimizerSDK } from './src/sdk/PdfOptimizerSDK.js'; // Hubungkan ke input file PDF di website Anda PdfOptimizerSDK.attachToInput('#pdfInput', { maxSizeBytes: 2 * 1024 * 1024, // Garansi ukuran < 2 MB onSuccess: (files) => { console.log('File PDF terkompresi otomatis < 2MB:', files[0]); } });

3. Metode B: Kompresi Manual via API Function

import { PdfOptimizerSDK } from './src/sdk/PdfOptimizerSDK.js'; const pdfFile = document.getElementById('myPdfInput').files[0]; const compressedPdf = await PdfOptimizerSDK.compress(pdfFile, { maxSizeBytes: 2 * 1024 * 1024 }); const formData = new FormData(); formData.append('document', compressedPdf); await fetch('/api/upload-pdf', { method: 'POST', body: formData });

Dokumentasi Integrasi MediaOptimizer SDK

Panduan integrasi modul kompresi media video/audio otomatis ke website Anda. Setiap kali pengguna mengunggah video besar (misal 50 MB - 300 MB), SDK akan mengompresinya secara otomatis menjadi kurang dari 15 MB (< 15 MB) tanpa watermark dan tanpa mengirim file ke server eksternal.

1. Keuntungan Integrasi Client-Side Media Engine

  • Bebas Watermark & Bebas Biaya Server: Pemrosesan video dilakukan 100% di browser pengguna tanpa membebani RAM/GPU server.
  • Kualitas Suara & Layar Terjaga: Bitrate disesuaikan secara cerdas menjaga rasio layar dan kejelasan audio.
  • Hemat Storage Database: Server hanya menyimpan file video terkompresi < 15 MB.

2. Metode A: Auto-Attach pada Input File Video

import { MediaOptimizerSDK } from './src/sdk/MediaOptimizerSDK.js'; // Hubungkan ke input file video di website Anda MediaOptimizerSDK.attachToInput('#videoInput', { maxSizeBytes: 15 * 1024 * 1024, // Garansi ukuran < 15 MB onSuccess: (files) => { console.log('File video terkompresi otomatis < 15MB:', files[0]); } });

3. Metode B: Kompresi Manual via API Function

import { MediaOptimizerSDK } from './src/sdk/MediaOptimizerSDK.js'; const videoFile = document.getElementById('myVideoInput').files[0]; const compressedVideo = await MediaOptimizerSDK.compress(videoFile, { maxSizeBytes: 15 * 1024 * 1024 }); const formData = new FormData(); formData.append('video', compressedVideo); await fetch('/api/upload-video', { method: 'POST', body: formData });

Dokumentasi Integrasi SecurityGuardSDK

Otomatiskan verifikasi Magic Bytes dan hapus lokasi GPS rahasia dari foto pengguna sebelum diunggah ke Unara Storage.

1. Otomatiskan Input Validation Interceptor

import { SecurityGuardSDK } from './src/sdk/SecurityGuardSDK.js';

SecurityGuardSDK.attachToInput('#fileUpload', {
  onSuccess: (cleanFiles) => {
    console.log('File terverifikasi aman & bebas GPS:', cleanFiles[0]);
  }
});

2. Panggilan Fungsi Programatis

import { SecurityGuardSDK } from './src/sdk/SecurityGuardSDK.js';

const userFile = event.target.files[0];
const cleanFile = await SecurityGuardSDK.validate(userFile);

// cleanFile telah dibersihkan dari data lokasi GPS rahasia

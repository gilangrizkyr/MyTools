Dokumentasi Integrasi DocOptimizerSDK

Integrasikan pengoptimalan otomatis file Word (.docx), Excel (.xlsx), dan PowerPoint (.pptx) ke dalam website atau sistem penyimpanan Unara Storage Anda.

1. Integrasi 1 Baris Kode HTML Input Interceptor

Otomatis mencegat `` di formulir upload website Anda:

import { DocOptimizerSDK } from './src/sdk/DocOptimizerSDK.js';

DocOptimizerSDK.attachToInput('#docInput', {
  onSuccess: (files) => {
    console.log('Dokumen Word/Excel/PPT berhasil dikompresi:', files[0]);
  }
});

2. Panggilan Fungsi Programatis

import { DocOptimizerSDK } from './src/sdk/DocOptimizerSDK.js';

const originalDoc = event.target.files[0];
const compressedDoc = await DocOptimizerSDK.compress(originalDoc);

const formData = new FormData();
formData.append('document', compressedDoc);

await fetch('/api/upload', {
  method: 'POST',
  body: formData
});

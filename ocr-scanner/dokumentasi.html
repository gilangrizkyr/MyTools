Dokumentasi Integrasi ReceiptOcr SDK

Panduan integrasi modul OCR struk & nota pembayaran otomatis ke website Anda. Setiap kali pengguna mengunggah foto struk/nota, SDK akan membaca teks secara 100% Client-Side dan mengisi kolom form (Nama Toko, Tanggal, Total Biaya) secara otomatis.

1. Keuntungan Integrasi Client-Side OCR SDK

  • Bebas Biaya API Server: Pemrosesan OCR berjalan 100% di browser pengguna tanpa langganan Google Vision/AWS Textract.
  • Otomatisasi Form Reimbursement: Pengguna tidak perlu lagi memasukkan nominal dan nama toko secara manual.
  • Garansi Privasi Data Keuangan: Foto struk tidak pernah di-upload ke server luar.

2. Metode A: Auto-Attach pada Form Reimbursement Website

import { ReceiptOcrSDK } from './src/sdk/ReceiptOcrSDK.js'; // Hubungkan ke input foto struk & petakan ke elemen input form ReceiptOcrSDK.attachToForm('#receiptInput', { merchantInput: '#storeNameInput', dateInput: '#transactionDateInput', amountInput: '#totalAmountInput' }, { onSuccess: (data) => { console.log('Ekstraksi OCR Berhasil:', data); } });

3. Metode B: Ekstraksi Data Manual via API Function

import { ReceiptOcrSDK } from './src/sdk/ReceiptOcrSDK.js'; const imageFile = document.getElementById('myInput').files[0]; const metadata = await ReceiptOcrSDK.extract(imageFile); console.log('Merchant:', metadata.merchant); console.log('Tanggal:', metadata.date); console.log('Total Biaya:', metadata.totalAmount);
